## 🤖 How I work with AI (my actual edge)

I have worked in a team where AI-assisted delivery was mandatory and measured — so I learned to do it properly instead of casually:

1. **Small written spec** before any code exists.
2. **Agent implementation** in small, reviewable chunks.
3. **My review pass**: I read every line I ship, check it against the spec, and run it.
4. **Tests + documentation** as part of "done", not as decoration.

My personal harness (Orsod AI, on Pi + Engram memory) is **frozen at v1.0** — tooling serves delivery; it is not the job.
